Open Salamander: Plugins: Samandarin Update Notifier: Using the Plugin

Plugin Updates

The Check plugin updates... command opens the Plugin Updates window. It checks installed plugins and extensions against JSON catalogs and shows the installed version, the latest version and the status of each entry.

To check plugin updates:

Menu:Plugins/Samandarin Update Notifier/Check plugin updates...

Status

  • Current – the installed version matches the catalog.
  • Update available – the catalog offers a newer version.
  • Different version – the installed version differs from the catalog and no update is offered, for example because it is newer.
  • Not installed – the catalog entry is not installed.
  • Not in catalog, Unknown version or Catalog error – the plugin could not be compared.

Check Show only updates to hide entries that are up to date. Use Refresh to load the catalogs again. The context menu of the list copies a value or a whole row.

Installing and updating

Select an entry to see its details, including the description, the download page and its security capabilities (network access, external processes, script execution). Official plugin and extension .7z packages can be installed or updated with the Install or Update button. The plugin downloads the package, verifies its SHA-256 digest from the catalog and the Authenticode signature of its modules, and installs it after Open Salamander exits. Missing dependencies are offered together with the selected package. For other entries, Open plugin webpage opens the plugin's web page instead.

Catalog sources

Click Configure sources to edit the list of catalog URLs, one URL per line, and confirm it with Save sources.
