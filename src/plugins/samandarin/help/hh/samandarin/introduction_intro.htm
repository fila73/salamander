Introducing the Samandarin Update Notifier

The Samandarin Update Notifier plugin keeps Open Salamander Samandarin and its plugins up to date. It checks GitHub releases for a newer Samandarin build and compares installed plugins and extensions with the plugin catalogs.

The plugin adds two commands to its menu in the Plugins menu:

  • Check updates now checks whether a newer Samandarin build is available.
  • Check plugin updates... lists installed plugins and extensions and offers updates.

The update logic is implemented in the Samandarin.Managed.dll assembly, which must be located next to samandarin.spl.

See Using Plugins for a description of basic work with plugins.
