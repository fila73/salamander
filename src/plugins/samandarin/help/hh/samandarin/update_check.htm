Open Salamander: Plugins: Samandarin Update Notifier: Using the Plugin

Checking for Samandarin Updates

The Check updates now command compares the running Samandarin version with the latest release published on GitHub. If a newer build is available, the plugin shows the current and the latest version and offers to open the download page in your web browser. Nothing is downloaded or installed automatically.

To check for updates:

Menu:Plugins/Samandarin Update Notifier/Check updates now

Automatic checks

Open the plugin configuration (Plugins/Plugins Manager, select the plugin and click Configure) to choose when Samandarin checks for a newer build:

  • Check when Salamander starts runs the check each time Open Salamander starts.
  • Periodic check repeats the check Daily, Weekly or Monthly, or never when set to Disabled.

The configuration window also shows the time of the last automatic check and the last known release. Click Check now to run the check immediately.
